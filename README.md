# Ротация

Персональная mobile-first PWA для истории употребления отдельных продуктов и расчёта даты, когда их можно вернуть в рацион. Приложение работает без регистрации, не отправляет данные наружу и хранит основную базу в IndexedDB браузера.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Vite покажет локальный адрес. Для проверки на телефоне запустите `pnpm dev --host` и откройте показанный адрес с Android-устройства в той же сети.

## Проверка и production-сборка

```bash
pnpm test
pnpm build
pnpm preview
```

Готовая статическая версия создаётся в `dist/`. При отправке изменений в ветку `main` GitHub Actions запускает тесты, собирает приложение и публикует папку `dist/` в GitHub Pages.

Для первого включения публикации откройте в репозитории **Settings → Pages** и выберите **GitHub Actions** в поле **Source**. Адрес проекта будет иметь вид `https://<имя-пользователя>.github.io/foodly-app/`.

## Установка на Android

Откройте production-версию в Chrome, затем выберите меню браузера → «Установить приложение» или «Добавить на главный экран». После первого полного открытия интерфейс доступен без интернета.

## Данные и резервная копия

Данные хранятся только в IndexedDB текущего браузера и профиля. На экране «Продукты» нажмите кнопку с иконкой базы данных:

- «Сохранить» выгружает JSON-резервную копию;
- «Восстановить из файла» сначала проверяет файл и показывает итог, а после подтверждения атомарно заменяет текущую базу.

Удаление данных сайта в настройках браузера удалит локальную базу, поэтому перед очисткой браузера сохраните резервную копию.

Данные разных устройств не синхронизируются. Каждый пользователь сайта получает отдельную локальную базу в своём браузере.
